# Summary of Research & Design Plans

## Summary of Research

### Observational Study
The study showed that users had a hard time navigating Craigslist and finding certain features. Participants of the study had difficulty finding apartments in a specific location, finding a gig versus a job, and selecting categories when creating a listing.

### Heuristic Evaluation
The evaluation found three main problems with Craigslist's homepage:
* Crowded Layout with many links
* Unclear category names that may confuse users
* Poor placement of the location selector, making it hard to notice

### Survey
The survey showed that the participants had difficulty finding a specific category because of the large amount of text and links. However, the participants suggested to keep the existing categories. The main conclusion to fix Craigslist was to reduce the amount of text and links and make navigation easier.

### Takeaway
Overall, these findings from the research suggest that Craigslist needs a simpler layout, clearer navigation, and a more intuitive way for users to find certain listings and create posts.

## Focused List of Design Plans
We plan to make the following changes based on our research:

## 1. Simplify Layout of the Homepage
* Reduce the number of links displayed at one time
* Display the "main" categories first and allow users to expand them to see subcategories
* Add more spacing between categories and sections to make the homepage less crowded with information

## 2. Improve Navigation of Categories
* Use more clear and descriptive names for confusing categories
* Add icons or visuals to help users identify categories more easily
* Improve the visual hierarchy of the homepage so users can distinguish between main categories and subcategories instead of seeing walls of text links

## 3. Improve Location Selector
* Move the location selector to a more visible location near the top of the homepage
* The user's currently selected location (city) should be clearly displayed
* Make it easier to search for listings near specific locations by allowing users to search for listings within a specific distance of a selected location

## 4. Improve the Searching Experience
* Make searching filters easier to find and understand
* Improve the layout/organization of filters for the different listing types (e.g., jobs vs housing)
* Make it easier for the user to distinguish between jobs and short-term gigs

## 5. Simplify the Listing Process
* Make the button/option to create a listing more obvious and visible
* Use clearer labels for fields and selecting categories
* Adding autocomplete for certain entries (e.g., address autocomplete to simplify adding a location)
* Make the reply button/option more visible and make it clear that this is how users can contact listing owners
