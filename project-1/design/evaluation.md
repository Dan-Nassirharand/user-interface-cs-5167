# Evaluation

User evaluations of [vanilla UI sketch](./sketching/vanilla-ui-sketch.png)

Users were given an overview of the class and project, asked to share their thoughts, were presented with vanilla UI sketch, and verbally walked through each idea. In regards to the latter, no information was provided tha was not already present in the sketch.

## Interview 1: <"Valentina" (Anonymous) >

- How to wash the sock liner liner?
  - Is a soccer player who has hygiene concerns
- Loves the ability to dynamically change shoe color
- Does not like that the laces would change color along with the shoe.
  - Would rather have laces match the color of the sock liner
- Thinks the movement enhancement is cool, but must make sure button is not bulky

## Interview 2: <"DJ X" (Anonymous) >

- Generally curious about technical implementation
- Liked the color change idea
- Suggested to look at different
  shoe-tightening options instead of aglets.
  - Other tightening mechanisms might lend themselves better to the UI.

## Interview 3: <"Joe" (Anonymous) >

- Likes all, overall interesting
- Color-changing shoe was favorite feature
  - Would be something he would use daily
  - Thinks most people often like to match the color of their shoes with outfits.
- Movement boost idea would be especially good for older people
  - Doesn't see self or younger demographic using this every day as there is no need for it
  - Would invest in it as an accessibility solution.
