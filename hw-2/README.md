Generative models were used in the following applications:
- Comparing approaches to demonstrate the use of the map function on an array
    - Validating both an inline arrow function and a named function as valid approaches
- Comparing between the `+=` and `+` string operators
- Exploring semantics of the `map` function
- Exploring Java execution phases
    - Learned that functions are hoisted during the creation phase, meaning they do not need to be forward-declared
